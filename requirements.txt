# The routing service itself needs no third-party package (see Dockerfile).
# These are for the benchmarks and tests, and the versions are PINNED so that
# local runs and CI install the same thing.
#
# Why pinned instead of >=: numpy's Generator (PCG64) only promises a stable
# stream within one feature release (NEP 19). With >= CI would install the
# newest release, the sampled numbers could change and --check would fail for
# a reason unrelated to the code. The paired bootstrap is pure stdlib
# (campus_bus/stats.py) and the OD pairs are frozen in bench/od_pairs.json;
# the remaining numpy randomness is in the GPS section, and the pin locks it.
#
# Keep this file ASCII-only: older pip (e.g. 23.2.1, bundled with Python 3.11)
# decodes it with the locale codec (GBK on zh-CN Windows) and fails on non-ASCII.
numpy==1.24.3
scikit-learn==1.3.0
# networkx is used only by the tests, as an independent third-party solver on a
# frozen snapshot (tests/test_all.py::ThirdPartyOracle).
networkx==3.1
